# 九号青龙任务

将九号 App 的每日签到、分享领奖和盲盒检查合并为一个青龙面板任务。脚本顺序固定为：每日签到 → 分享领奖（可选）→ 盲盒检查与自动领取；运行结束后只发送一次汇总通知。

本项目基于 [Bingwithyou/automation-scripts](https://github.com/Bingwithyou/automation-scripts) 的 `ninebot/` 模块抽离并改造成单任务脚本，按上游 [MIT 许可证](LICENSE) 发布。

## 功能说明

- 每日签到。
- 通过抓取的分享回调载荷执行分享任务，并领取对应奖励。
- 查询未开启盲盒，自动领取已达到条件的盲盒奖励。
- 优先调用青龙自带的 `notify.py` 发送一次结果汇总；没有该模块时只输出青龙任务日志。

## 青龙安装

### 1. 安装 Python 依赖

在青龙面板的“依赖管理”中新建 Python 依赖：

```text
requests
```

也可以在青龙容器终端运行：

```bash
pip3 install requests
```

### 2. 配置环境变量

在青龙面板“环境变量”中创建以下变量。敏感值只保存在环境变量中，不要提交到仓库或日志截图。

| 变量名 | 是否必填 | 获取位置与说明 |
| --- | --- | --- |
| `NINEBOT_TOKEN` | 是 | 抓取签到接口 `/portal/api/user-sign/v2/sign`，复制请求头 `Authorization` 的完整值。 |
| `NINEBOT_DEVICE_ID` | 是 | 从同一次签到请求中复制请求头 `device_id` 的值。 |
| `NINEBOT_SHARE_PAYLOAD` | 否 | 抓取 `circle/v1/share-callback`，将完整 Request Body 保存为合法 JSON。未设置时仅跳过分享领奖，不影响签到与盲盒。 |

请仅使用自己的账号和设备信息。令牌失效后重新抓取并更新环境变量。

### 3. 订阅脚本

在青龙面板终端执行：

```bash
ql repo https://github.com/qq1739920004/ninebot.git "ninebot" "tests" "" "main" "py"
```

导入后会创建 `ninebot.py` 任务。脚本内置的默认 cron 为每天北京时间 07:00：

```text
0 7 * * *
```

你可以在青龙任务页按自己的需要修改定时，或直接点击“运行”做首次验证。

## 通知与日志

脚本会把每一步标记为成功、失败或跳过，并生成一次汇总。若青龙已有 `notify.py`，会使用面板“系统设置”中已启用的通知渠道；通知不可用时不影响任务日志输出。

以下情况会被记录到汇总中，但不会阻止后续步骤执行：

- 签到、分享、领奖或盲盒接口返回业务失败；
- 网络请求异常、HTTP 非 200 或接口返回非 JSON；
- 分享载荷格式错误或未配置。

缺少 `NINEBOT_TOKEN` 或 `NINEBOT_DEVICE_ID` 时，脚本会在发起网络请求前退出。

## 手动运行

先在当前 shell 配置环境变量，再运行：

```bash
python3 ninebot.py
```

实际青龙脚本目录会随面板版本和订阅名称不同而变化，推荐从任务页点击“运行”。

## 风险说明

本脚本依赖第三方接口。接口字段、任务 ID、活动规则、登录状态及风控策略可能随时变化，无法保证长期可用。请自行评估平台规则与账号风险；本项目仅供个人学习和研究使用。
